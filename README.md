#### [Prepzo](https://github.com/AdityaMani-2003/Prepzo) — AI Technical Interview Platform
A full-stack web app that simulates technical interviews across coding, system design, SQL, and resume grilling.
- Built with Next.js 16, React 19, TypeScript, Supabase (PostgreSQL), and Gemini 2.5 Flash.
- Includes company-specific interview tracks, voice input for verbal rounds, code editor, and scoring breakdown.
- Uses Supabase Row-Level Security (RLS) for user data isolation and authentication via Google OAuth.
- **Live Demo:** [prepzo-one.vercel.app](https://prepzo-one.vercel.app/)

A productivity assistant that syncs with Google Calendar and Gmail (read-only) to answer natural-language questions about your schedule and correspondence.
- Built with React, Vite, Node.js, Express, and Google Gemini function calling.

- **Live Demo:** [personal-brain-c5bn.onrender.com](https://personal-brain-c5bn.onrender.com/)
